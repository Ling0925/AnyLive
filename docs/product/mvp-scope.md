# MVP 范围说明书（P1 内测）

对应阶段：[01-阶段与里程碑 · P1](./01-阶段与里程碑.md)  
验收目标：**20 主播 / 500 用户 dogfood**；账本不平衡 = 0。

---

## 1. 用户故事（必须）

### 观众
1. 用邮箱 OTP（或等价）注册/登录  
2. 浏览热门/关注中的直播间  
3. 进入直播间观看（HLS 主路径）  
4. 发送聊天消息、看到他人消息与系统提示  
5. 查看礼物栏、送礼、看到动画与余额变化  
6. 关注主播  
7. 举报房间或用户  

### 主播
1. 登录后创建/管理自己的房间  
2. 获取推流信息，使用 **OBS** 或 App 内开播  
3. 开播后观众可进入；停播后状态正确  
4. 看到聊天与礼物（至少聊天+礼物通知）  
5. 被运营强关后无法继续播  

### 运营（Admin）
1. 登录后台（RBAC 最小：admin 角色即可）  
2. 查看在线/历史房间，预览流（HLS 可接受）  
3. 封禁用户、禁言、房间强关  
4. 配置礼物目录  
5. 处理举报队列  
6. 写操作有审计日志

## 2. 功能清单

| 模块 | 必须 | 可简化 | 不做 |
|---|---|---|---|
| 登录 | Email OTP + JWT | OAuth 可后置 | 复杂风控设备图谱 |
| 资料 | 昵称头像 | 丰富资料页 | 创作者认证体系 |
| 房间 | CRUD、开播停播状态机 | 封面审核 | 多人房型 |
| 媒体 | 推流 key、播放 URL、webhook 状态 | 单码率 | 多码率自适应（可 P2） |
| 聊天 | 文本、入房、限流 | 表情回复 | 私信体系 |
| 礼物 | 目录、送礼、动画事件 | 连击简化 | 全屏高级特效编排器 |
| 钱包 | 余额、ledger、幂等送礼 | 充值 Stripe test | 提现/分成结算 |
| 社交 | 关注、热门/关注 feed | 搜索 | 推荐模型 |
| 审核 | 举报、封禁、强关 | 机器审核 API | 自研 AI |
| H5 | 观看+分享 | 登录送礼 | 完整 App 能力镜像 |
| 连麦/PK | — | — | **整期不做** |
| 短视频/电商 | — | — | **整期不做** |

## 3. 验收标准（Exit）

### 功能
- [x] 新用户 10 分钟内完成：注册 → 看播 → 发言 → 送礼（测试币） — 控制面 + dogfood/API/Flutter/H5；真人计时仍靠运营  
- [x] 主播 OBS 推流成功，Flutter 与 H5 均可播放 — 控制面 + 媒体冒烟 + 手册；连续一周 dogfood 仍人工  
- [x] 停播/强关后播放端有明确结束态 — API/Flutter/H5  
- [x] 重复提交同一 `Idempotency-Key` 送礼不双扣 — 单测 + 集成  
- [x] Admin 封禁用户后无法发言/开播（按策略） — API + 管理台  

### 质量
- [ ] 无 P0 打开缺陷 — 人工缺陷会  
- [x] 资金相关自动化测试通过  
- [x] 同房 1k WS 压测脚手架 + 报告模板归档（`scripts/loadtest/` + `reports/ws-1k-baseline-TEMPLATE.md`；**实填数仍待全量跑**）  
- [ ] 中端 Android + 近两代 iPhone 冒烟通过 — 真机人工（模板：`reports/device-matrix-TEMPLATE.md`）  

### 合规钩子
- [x] 注册可见隐私政策/条款链接  
- [x] 年龄声明字段存在  
- [x] 举报入口可用  
- [x] 账号删除/导出 API（实质 payload）+ 移动端 + 文档

## 4. 测试账号与演示脚本

**演示脚本（15 分钟）：**

1. Admin 配置 3 个礼物  
2. 主播 A 开播（OBS）  
3. 观众 B/C 进房聊天  
4. B 充值测试币并送礼  
5. A 端/全员看到礼物效果  
6. C 举报 → Admin 处理 → 可选强关  
7. 展示钱包流水与审计日志  

**可执行走查（预检 + Admin `data-testid` + 签字）：** [admin-ops-15min-demo.md](../runbooks/admin-ops-15min-demo.md)（V-AD-1；仅人工签字关闭）。本地栈：[go-live-local.md](../runbooks/go-live-local.md) §2。
