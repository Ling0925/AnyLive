# 01 · 阶段与里程碑

关联：[00-规划总览](./00-规划总览.md) · [02-WBS与排期](./02-WBS与排期.md) · [海外合规](../compliance/海外合规与上架闸门.md)

每个阶段有**进入条件 / 退出条件 / 交付物 / 合规闸门 / 主要风险**。阶段可部分重叠（P3 与 P4），但退出门禁不可跳过。

---

## P0 · 基建（W1–W2）

**目标：** 可并行开发的工程底座，契约 v0 冻结。

| | 内容 |
|---|---|
| **进入** | 架构 ADR 已批准；核心 8 人到位；云账号/域名就绪 |
| **退出** | monorepo 可 clone 即跑；CI 绿；OpenAPI `auth/user/room` v0 冻结；docker-compose 起 PG/Redis/NATS/Centrifugo/SRS |
| **交付物** | 仓库骨架、`contracts/openapi`、基础 CI、dev 环境文档、错误码表 v0 |
| **合规闸门** | 密钥不进库；环境分离（dev/stage）；隐私政策占位页 URL |
| **风险** | 契约扯皮拖慢三端 → TL 第 3 天强制冻结 v0 |

**史诗：** monorepo · CI/CD · OpenAPI 骨架 · compose 依赖 · 观测最小集（tracing + health）

---

## P1 · MVP 内测（约 W3–W12，~10 周）

**目标：** 20 主播 / 500 用户 dogfood；开播→观看→聊天→礼物→钱包（沙箱）→后台强关闭环。

| | 内容 |
|---|---|
| **进入** | P0 退出；媒体轨 SRS 可推可拉 |
| **退出** | 验收清单全过；账本不平衡=0；1k 同房 WS 压测基线；无未关闭 P0 |
| **交付物** | Flutter 内测包、Admin 可用、H5 可观看分享、Runbook 草稿、压测报告 |
| **合规闸门** | 年龄门槛 UI 钩子；举报入口；ToS/Privacy 链接；数据删除 API 桩 |
| **风险** | 礼物双花、播放器碎片、IM 重连风暴 |

### P1 子里程碑

| 里程碑 | 约周 | 标志 |
|---|---|---|
| M1.1 可登录可建房 | W4 | OTP/邮箱登录 + room CRUD |
| M1.2 可推可看 | W5–W6 | OBS/手机推流，Flutter/H5 播放 |
| M1.3 可聊 | W7–W8 | 入房、弹幕、在线数 |
| M1.4 可打赏 | W9–W10 | 钱包账本 + 礼物动画 + 幂等 |
| M1.5 可运营 | W10–W11 | Admin 封禁/强关/礼物配置/举报 |
| M1.6 可内测 | W12 | Dogfood 周 + 压测 + 缺陷清零 |

**明确不做：** PK、多人连麦、真实支付（可用 Stripe test）、完整推荐、AI 审核。

---

## P2 · 封闭公测 / Soft Launch（约 W13–W20）

**目标：** 邀请制对外；商店内测通道；支付沙箱→可控真实小流量。

| | 内容 |
|---|---|
| **进入** | P1 退出；崩溃率与核心漏斗可观测 |
| **退出** | TestFlight + Play Internal 通过；Stripe test 全链路 + IAP 沙箱；邀请 2k+ 用户；on-call 初级 |
| **交付物** | 生产级 stage 环境、CDN 生产配置、内容安全策略 v1、客服/举报 SOP |
| **合规闸门** | 隐私政策正式版、年龄分级材料、GDPR DSR 流程可人工+API、应用商店元数据 |
| **风险** | 商店拒审、支付账号地区限制、CDN 费用超预期 |

### P2 子里程碑

| 里程碑 | 标志 |
|---|---|
| M2.1 生产拓扑 | 独立 stage/prod；密钥托管；备份 |
| M2.2 商店内测 | iOS/Android 内测分发 |
| M2.3 支付就绪 | Stripe + IAP 沙箱；账本对账任务 |
| M2.4 软开量 | 邀请码/白名单；限流与防刷 |

---

## P3 · 连麦 / PK（约 W21–W28，可与 P4 前半重叠）

**目标：** 台上小 N 互动，E2E ≤400ms；台下仍走 CDN 广播。

| | 内容 |
|---|---|
| **进入** | P2 基本稳定；LiveKit 集群 stage 可用 |
| **退出** | 双人连麦 + 基础 PK 玩法上线；失败率 <2%；成本看板可读 |
| **交付物** | LiveKit 集成、合流/转推策略（台上 WebRTC → 必要时转推 RTMP/HLS 给观众）、Flutter 连麦 UI |
| **合规闸门** | 连麦场景额外举报理由；录制同意（若录） |
| **风险** | 弱网质量、分钟费、Flutter WebRTC 设备兼容 |

**拓扑原则：** 台上 SFU（LiveKit），台下 CDN；禁止全员进 SFU。

---

## P4 · 增长与运营（约 W24–W32）

**目标：** 可运营、可分析、创作者有基础工具。

| | 内容 |
|---|---|
| **进入** | 软上线数据 ≥2 周 |
| **退出** | 事件埋点完整；首页轻推荐 v1；运营配置后台；审核队列 SLA |
| **交付物** | 分析管道（事件 → 仓/看板）、创作者中心（数据/禁言管理）、礼物经济配置增强 |
| **合规闸门** | 同意管理（分析 cookies/SDK）、数据最小化审查 |
| **风险** | 埋点污染、推荐过度耦合、审核人力不足 → 第三方审核 API 钩子 |

---

## P5 · 正式上线 GA（约 M7–M9）

**目标：** 公开上架与公开下载；生产 on-call；容量达标。

| | 内容 |
|---|---|
| **进入** | P2 退出 + P3 核心可用（PK 可作为 GA 当日开关）+ P4 基础看板 |
| **退出** | 双商店公开；支付生产；可用性目标承诺；事故演练完成；容量：~10k 同时在线 / ~100 路直播设计验证 |
| **交付物** | 生产 Runbook、SLO 看板、备份恢复演练记录、发布开关体系 |
| **合规闸门** | 见 [海外合规与上架闸门](../compliance/海外合规与上架闸门.md) 全表勾选 |
| **风险** | 活动流量打爆、礼物刷子、政策变更 |

**GA 当日功能开关建议：** 公开注册、真实支付、PK（可灰）、录制（可关）。

---

## P6 · 中国市场适配（可选，GA 后）

**不阻塞海外。** 通过 Provider 替换完成：

| 端口 | 海外实现 | CN 实现（示例） |
|---|---|---|
| MediaProvider | LiveKit + CF | 腾讯 CSS / 阿里直播 + TRTC |
| Realtime | Centrifugo | 腾讯 IM 或继续 Centrifugo |
| PayProvider | Stripe/IAP | 微信/支付宝（合规主体） |
| KycProvider | 年龄/地区策略 | 实名 + 人脸等 |
| PolicyEngine | GDPR/年龄 | 防沉迷/区域开关 |

进入条件：独立主体与资质策略明确（非本技术规划范围）。

## 阶段依赖图

```
P0 ──► P1 ──► P2 ──► P5(GA)
              │       ▲
              ├──► P3 ┤
              └──► P4 ┘
P6 仅依赖 GA 后业务决策（虚线）
```

**硬依赖：**

- P1 媒体可看 ← P0 SRS/CDN 通
- P1 礼物 ← 钱包账本 + Centrifugo
- P2 商店 ← 隐私政策 + 年龄 + 崩溃率
- P3 ← LiveKit + Flutter RTC 稳定
- P5 ← 支付生产 + on-call + 压测门禁
