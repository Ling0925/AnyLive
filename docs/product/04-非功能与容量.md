# 04 · 非功能需求与容量阶梯

关联：[01-阶段与里程碑](./01-阶段与里程碑.md) · [05-风险与第一刀](./05-风险与第一刀.md)

海外创业期容量目标：**务实可验证**，不为「百万同时在线」做虚假设计，但架构不堵死水平扩展。

---

## 1. 延迟 SLO

| 场景 | 目标 | 可接受上限 | 阶段生效 |
|---|---|---|---|
| API 非支付读写 P95 | ≤150ms（同区域） | 300ms | P1 |
| 聊天端到端 P95 | ≤300ms | 500ms | P1 |
| 礼物扇出 P95 | ≤500ms | 1s | P1 |
| 观众首帧 P95 | ≤3s | 5s | P1 |
| 秀场 glass-to-glass（HLS） | ≤5s | 8s | P1 |
| 连麦/PK E2E 中位 | ≤400ms | P95 ≤500ms | P3 |
| 支付确认到余额可见 | ≤5s | 30s（Webhook 重试） | P2 |

测量：客户端埋点 + 服务端 trace；分区（区域/网络类型）报表。

---

## 2. 可用性与可靠性

| 项 | P1 | P2 | P5 GA |
|---|---|---|---|
| API 月可用性 | 99.0% | 99.5% | 99.9% 目标（努力） |
| 计划内维护窗口 | 任意 | 每周固定 | 公告 + 开关 |
| RPO（DB） | 24h | 1h | ≤15min（或 PITR） |
| RTO | 最佳努力 | 4h | 1h |
| 账本正确性 | **不平衡 = 0** | 同左 | 同左 + 日对账 |

**金钱路径优先级高于观看路径：** 礼物/充值异常时宁可只读，不可静默错账。

---

## 3. 容量阶梯

| 阶梯 | 同时在线 | 并发直播 | 单房 CCU（聊天） | 触发阶段 | 验证方式 |
|---|---|---|---|---|---|
| L0 开发 | <50 | <5 | 50 | P0 | 手工 |
| L1 Dogfood | ~500–1k | ~20 | **1k 设计** | P1 退出 | k6/WS 压测 |
| L2 软上线 | ~5k–10k | ~50–100 | 1k–2k | P2 | 压测 + 限流 |
| L3 GA | ~10k–30k | ~100–200 | 2k | P5 | 压测 + 扩容演练 |
| L4 增长 | 100k DAU 量级 | 按成本扩 | 分片频道 | post-GA | 架构复盘 |

> 单房 1k CCU 指 **IM/聊天连接**，不是 SFU 订阅数。观众视频走 CDN，不进 LiveKit。

### 扩展杠杆（预先设计，按需启用）

1. Centrifugo 多节点 + Redis Engine  
2. API 无状态水平扩  
3. Postgres 连接池 / 只读副本（feed）  
4. 礼物 worker 多副本（按 room 分区消费）  
5. 媒体与 API 分集群  
6. CDN 多区域  

---

## 4. 压测门禁（阶段退出必过）

### P1 退出
- [ ] 同房 **1000** 个 WS 连接稳定 15min，消息丢失率 <0.1%  
- [ ] 送礼 **100 TPS** 突发 1min，账本平衡、无双花  
- [ ] 开播/停播 并发 20 路，无状态错乱  
- [ ] API 在 2× 预期 QPS 下 P95 不破线  

### P2 退出
- [ ] 全站模拟 5k 在线（混合观看+聊天）  
- [ ] Webhook 重放与乱序：入账仍幂等  
- [ ] 杀 API pod：客户端可恢复（重连+快照）  

### P5 退出
- [ ] L3 容量脚本通过  
- [ ] 区域故障演练（文档化手动切换）  
- [ ] 备份恢复实弹  

工具建议：k6（HTTP）、自研/第三方 WS 压测、直播推流用 ffmpeg 矩阵。

## 5. 安全基线

| 域 | 要求 | 阶段 |
|---|---|---|
| 传输 | 全站 TLS；证书自动续期 | P0 |
| 鉴权 | 短寿命 access token；refresh 可吊销 | P1 |
| 密钥 | 云密钥托管；不进 git | P0 |
| 推流 | stream key 单次/短时；防盗链播放 | P1 |
| 支付 | Webhook 验签；金额以服务端目录为准 | P1–P2 |
| 滥用 | 限流（IP/用户/房间）；设备指纹可选 | P1+ |
| 管理 | RBAC；高危操作双人（提现类 P4+） | P1 / P4 |
| 审计 | admin 写操作全量审计 | P1 |
| 依赖 | 镜像扫描、Rust/JS 漏洞 CI | P2 |

**禁止：** 长寿命不可吊销 JWT；客户端上报余额为准；管理员共用账号。

## 6. 观测与告警

### 黄金信号
- 流量：QPS、WS 连接数、开播路数  
- 延迟：API/聊天/礼物/首帧  
- 错误：5xx、webhook 失败、IM 发布失败  
- 饱和：CPU/内存/PG 连接/Redis 内存/CDN 带宽  

### 业务告警（P1 起）
- 账本对账失败  
- 礼物失败率突增  
- 开播成功率下降  
- 强关/封禁 API 失败  

### 日志
- trace_id 贯通 API → worker → webhook  
- 禁止记录 access token、完整 stream key、支付原始敏感字段

## 7. 客户端性能预算

| 项 | 预算 |
|---|---|

| 全屏礼物并发 | ≤3；超出排队/合并 |

| 包体积 | 关注首包；按 flavor 裁剪 |
| 启动到可交互 | 冷启动目标 <3s（中端机，不含首帧视频） |

---

## 8. 成本护栏（海外）

| 项 | 策略 |
|---|---|
| CDN 出口 | 台下观众不进 RTC；监控 GB 成本 |
| LiveKit 分钟 | 仅台上小 N；PK 结束即释放 |
| 对象存储 | 头像/录制生命周期策略 |
| 短信 OTP | 优先 Email/OAuth；SMS 限国家与频率 |
| 观测 | 采样率可调，避免 APM 账单爆炸 |

每月媒体+CDN 成本进 Admin 看板（P2+）。

## 9. 环境分级

| 环境 | 用途 | 数据 |
|---|---|---|
| local | 开发 compose | 假数据 |
| stage | 联调/狗食 | 可定期洗白 |
| prod | 正式 | 备份加密 |

prod 凭证与 stage 完全隔离；开发者默认无 prod DB 写权限。
