# 00 · 规划总览

## 1. 产品目标

打造海外市场优先的**秀场娱乐直播**产品（1→N 为主，连麦/PK 二期），支持：

- 主播手机/OBS 开播，观众移动端 + H5 观看
- 实时聊天、礼物打赏、虚拟币钱包
- 运营后台监管（封禁、强关、审核队列）
- 后续扩展：连麦/PK、增长运营、可选中国市场适配

技术基线锁定于 [技术评定与架构方案](../技术评定与架构方案.md)，本规划**不重新选型**，只做执行拆解。海外默认媒体组合：

| 平面 | 海外默认 | 备注 |
|---|---|---|
| 互动 WebRTC | **LiveKit**（自建或 Cloud） | 连麦/PK；MVP 可先只做单主播 |
| 秀场分发 | **SRS origin（开发）+ Cloudflare Stream / 自建 origin + Cloudflare CDN** | 观众 HLS/LL-HLS；成本可控时再评估 Mux/AWS IVS |
| 实时 IM | **Centrifugo** | 聊天/礼物/在线；不绑厂商 IM |
| 支付 | **Stripe + App Store / Google Play IAP**（RevenueCat 可选） | PayProvider 端口 |
| 隐私 | GDPR/CCPA 架构钩子 | 同意、导出、删除 |

中国相关（腾讯云/实名等）全部落在 **Provider 实现**，列为 **P6 可选**，不阻塞海外 GA。

## 2. 成功指标（按阶段）

| 阶段 | 产品指标 | 技术指标 | 质量指标 |
|---|---|---|---|
| **P1 内测** | 20 主播 / 500 用户 dogfood；日均开播 ≥10 场 | 同房 1k CCU 聊天压测通过；礼物账本不平衡 = 0 | 无 P0 资金事故；强关/封禁可用 |
| **P2 软上线** | 邀请制 2k–5k 用户；周留存可观测 | API 可用性 ≥99.5%；首帧 P95 ≤3s | 商店内测包过审；崩溃率 <1% |
| **P3 连麦/PK** | 连麦功能 DAU 渗透 ≥5% 开播场次 | 互动 E2E 中位 ≤400ms | 连麦失败率 <2% |
| **P4 增长** | WAU 环比提升；创作者工具使用率 | 推荐/首页接口 P95 ≤200ms | 审核队列积压 <24h |
| **P5 GA** | 公开上架；支付真实跑通 | 站点设计容量 10k 同时在线 / 100 路并发直播 | 合规清单全绿；on-call 就绪 |

## 3. 总时间线（8–12 人并行）

假设：**可从第 1 周起 8 人到位，第 4 周扩到 10–12 人**。

| 月 | 主目标 | 阶段 |
|---|---|---|
| **M1** | 基建 + 可推可看 + 登录房间 | P0 → P1 前半 |
| **M2** | 聊天 + 礼物 + 钱包 + Admin 核心 | P1 |
| **M3** | 内测闭环、压测、隐私钩子、商店内测包 | P1 退出 |
| **M4** | 封闭公测、支付沙箱→真实、内容策略 | P2 |
| **M5** | 软上线稳定、创作者基础工具 | P2 → P3 启动 |
| **M6–M7** | 连麦/PK、互动媒体完善 | P3 |
| **M7–M8** | 增长（分析、轻推荐、运营配置） | P4 |
| **M8–M9** | GA 闸门、容量、on-call、公开上架 | P5 |
| **M9+** | 可选 CN 适配 / 深化运营 | P6 |

```
W1  W4  W8  W12 W16 W20 W24 W28 W32 W36
|--P0-|------ P1 MVP ------|
              |---- P2 Soft ----|
                        |---- P3 PK ----|
                              |---- P4 Growth ----|
                                    |---- P5 GA ----|
                                              |-P6?-
```

**关键路径：** OpenAPI 冻结 → 房间+媒体 token → 移动端播放 → 礼物账本 → 支付 → 商店审核 →（并行）LiveKit 连麦。

## 5. 范围边界（规划级）

### 5.1 做（到 GA）

- 账号（邮箱/手机 OTP/第三方 OAuth 视地区）
- 房间生命周期、推流/播放、录制开关（可后置）
- 聊天、礼物、钱包、充值（Stripe/IAP）
- 关注与首页
- 举报、封禁、强关、审核队列
- 连麦/PK（P3）
- 基础数据分析与运营配置（P4）
- GDPR 导出/删除钩子、年龄门槛、隐私政策链接

### 5.2 明确不做（GA 前）

- 电商直播带货完整链路
- 短视频 Feed 作为主产品
- 自建全球边缘 CDN
- 完整 AI 审核（可用第三方 API 钩子，不做自研模型）
- 复杂多租户白标
- 中国 ICP/视听证流程（P6）
- Flutter Web 公网主站
- 业务微服务网格拆分
