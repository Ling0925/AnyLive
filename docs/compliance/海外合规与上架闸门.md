# 海外合规与上架闸门

> **性质：** 工程与产品检查清单，**不是法律意见**。上线前应由合格顾问审阅隐私政策、用户协议与目标市场要求。

市场默认：海外（美欧及多地区渐进开放）。中国资质见架构 ADR 的 P6，不在此展开。

## 3. 隐私与数据主体权利（GDPR/CCPA 向）

### 架构钩子（必须进设计）
| 能力 | 实现要点 | 阶段 |
|---|---|---|
| 同意记录 | 注册时政策版本号、时间、平台 | P1 |
| 访问/导出 | `GET /me/export` 异步任务 → 下载链接 | P1 桩 / P2 真 |
| 删除 | `DELETE /me` 匿名化 + 级联策略 | 同左 |
| 纠正 | 资料 PATCH | P1 |
| 限制处理 | 暂停个性化/分析 flag | P4 |
| 子处理方 | 云、CDN、支付、邮件、分析、审核 API 列表 | P2 |

### 数据分类（示例）
- **身份：** email、手机、OAuth id  
- **内容：** 聊天、录像、头像  
- **财务：** 账本、订单（保留周期更长，法律要求时）  
- **技术：** IP、设备、日志  

日志默认脱敏；禁止把 token/stream key 打进日志。

## 4. 年龄与儿童

- 默认定位 **非儿童应用**；注册年龄门槛（如 16+/18+ 按市场）。  
- 不向儿童定向；不收集已知儿童数据（COPPA 场景则需专项，默认避开）。  
- 直播与打赏对未成年策略：PolicyEngine 可按年龄关闭充值/打赏。

---

## 5. 支付与虚拟货币

| 项 | 要求 |
|---|---|
| 展示 | 清晰价格、币种、虚拟币不可兑换现金的表述（按当地法调整） |
| 收据 | 可查订单与账本流水 |
| 退款 | 映射 `order.refunded` → 账本冲正策略文档化 |
| IAP vs Web | 商店审核前书面策略；实现走 PayProvider |
| 税务 | Stripe Tax 等评估；不在客户端算税 |

P1 仅沙箱；P2 小流量真实；P5 生产监控拒付与异常。

## 6. 内容安全与社区

### 最低运营能力（P1）
- 用户举报（类型：色情、仇恨、骚扰、 enticement 等可配置）  
- 管理端：禁言、封号、房间强关  
- 审计日志  

### 增强（P2+）
- 第三方机器审核 API 钩子（图/音/视）——**可插拔，非自研模型**  
- 审核队列 SLA（如 24h）  
- 主播协议与重复违规升级  

### 知识产权
- DMCA/通知删除流程邮箱与工单（公开页）  
- 用户生成内容许可条款（用户协议）

## 8. 区域开放策略

建议 **白名单国家** 渐进：

1. 内测：团队所在地 + 英语国家小集  
2. 软上线：扩展支付可用区  
3. GA：按 CDN、支付、合规成本分批  

`PolicyEngine.region_enabled` / `live_enabled` / `payout_enabled` 从 Day1 进配置，避免硬编码。
